# Mi Kcao — sitio multipágina

## Estructura
- `index.html`: Inicio
- `finca-organica.html`: Finca orgánica
- `cafeteria-rooftop.html`: Cafetería rooftop
- `carta.html`: Carta
- `talleres.html`: Talleres
- `taller-cacao-chuncho.html`: Taller de cacao Chuncho
- `turismo-vivencial.html`: Turismo vivencial
- `tienda.html`: Tienda
- `mayoristas.html`: Mayoristas
- `nosotros.html`: Nosotros
- `contacto.html`: Contacto
- `assets/css/site.css`: estilos compartidos
- `assets/js/site.js`: interacciones compartidas
- `assets/js/locales.js`: traducciones en inglés, español, francés y alemán

## Cómo abrir
Abre `index.html` en el navegador y pulsa el selector de idioma para alternar entre inglés, español, francés y alemán. La selección se conserva al navegar entre páginas. Para publicarlo, sube toda la carpeta conservando la estructura de archivos. No subas solo el HTML de inicio: los estilos, las imágenes y las interacciones están en `assets/`.

## Antes de publicar
Verifica horarios, precios, teléfono, correo, dirección y enlaces de contacto. La información se conservó del material fuente; no se ha verificado comercialmente.
